## `data/vsop87b.dat` — VSOP87B（木星、土星两行）

| 项 | 值 |
|---|---|
| 来源 | `https://cdsarc.cds.unistra.fr/ftp/VI/81/VSOP87B.jup`（484,519 字节）与 `.../VSOP87B.sat`（848,939 字节），Bretagnon & Francou，Bureau des Longitudes |
| 取得日期 | 2026-10-10（`curl --ssl-no-revoke`；本机 schannel 连不上吊销服务器，见 T17） |
| 取用范围 | **只取 VARIABLE 1/2/3（L/B/R）里 body=5（木星）与 body=6（土星）的行**；其余行星仍走 `planets.gd` 的 JPL 近似根数 |
| 截断 | 保留 **A ≥ 1e-6 rad** 的项：木星 325 项 / 土星 522 项（原表 3,625 / 6,365 项），文件 40 KB |
| 截断误差 | 对未截断级数在 1800–2050 每半年一点逐点比：木星 **0.43″**、土星 **0.24″** 的最大位置误差 |
| 许可 | **公有领域 / 公开天文数据**（IMCCE/CDS 机读目录；VSOP87 由 Bureau des Longitudes 发布，无附加条款） |
| 格式 | 每行 `<body> <variable> <power> <A> <B> <C>`，项 = `A·cos(B + C·T)`，T 为自 J2000 的儒略千年（365250 天）。坐标系 = 日心黄道、**J2000 春分点**——与 `planets.gd::ELEMENTS` 同一坐标系，所以换行不需要任何转换 |

### 为什么换这两行（而不换别的）

JPL 的近似根数是**直线速率**拟合：水星到海王星里只有木星、土星跟着**大不等式**（5:2 共振）摆，
直线拟合跟不上——对 Horizons 实测 1800–2050 差 425″ / 631″，超过 A6 的 5′。
两张表都实现过量过（计划 G33），都不行，所以这两行改由 VSOP87 级数回答。
其余五颗仍在 5′ 内（水星 21″、金星 42″、火星 60″、天王星 81″、海王星 59″，同一轮实测），保持不变。

## 二十八宿的**星官表**（`backgrounds/sky/mansion_figures.gd`，2026-10-10）

| 项 | 值 |
|---|---|
| 星名 → 现代星名 | **伊世同《中西对照恒星图表》(1981)** 的对照表，经中文维基百科的星官条目转述（`角 (星官)` / `平道` / `天田 (星官)` / `周鼎 (星官)` / `进贤 (星官)` / `天门 (星官)` / `平 (星官)` / `库楼` / `柱 (星官)` / `衡 (星官)` / `南门 (星官)`），取得日期 2026-10-10（`zh.wikipedia.org/w/api.php` 的 wikitext，只读对照关系） |
| 进仓的东西 | **只有"哪颗星叫哪个星名"**：`角宿一 = α Vir`、`库楼二 = η Cen`、`柱五 = a Cen` … 按仓里星表自己的编号写（拜耳字母 / 弗氏号 / HR）。**没有坐标、没有连线数据进仓**（§6.3 红线） |
| 五颗拉丁字母拜耳星 | BSC5 **不写任何拉丁字母拜耳名**（实测：全表 Name 字段里没有 `g Cen` / `d Cen` / `f Cen` / `D Cen` / `a Cen`），所以这五颗只能按 HR 号取。HR 号取自 **SIMBAD** 的标识符表（`sim-id?Ident=g+Cen` …，取回 `HR 5192 / 5089 / 4940 / 4652 / 5378`），并**逐颗与仓里 BSC5 那条记录对位置**：赤经赤纬一致到 **0.001°**，B、V 也是同一颗（`HD 120323` = HR 5192 = `g Cen` …） |
| 图线形状的独立对照 | **Stellarium 的中国星空 sky culture**（`skycultures/chinese/index.json`，取得日期 2026-10-10，643 KB，**不进仓**）：它的 312 个星官按 **HIP 号**给连线。把每个 HIP 用 SIMBAD 解成位置、就近落到本仓星表上，与伊世同表**逐星逐坨比对**（角宿 11 个星官：星相同、分坨相同）。**唯一分歧**：它的 `库楼` 第九颗是 **HD 107931**，伊世同表是 **库楼九 = D Cen**（`HD 106321`）——取后者，`mansion_figures.gd` 里写明了 |
| 不画的部分 | 清《仪象考成》给每个星官加的**增星**（角宿 41 星 → 95 星那 54 颗）不进表：它们是清代的补星，不是星官自己的星 |

## `data/constbnd.dat` + `data/bound_20.dat` — 星座边界（Davenhall & Leggett 1989）

| 项 | 值 |
|---|---|
| 来源 | `https://cdsarc.cds.unistra.fr/ftp/VI/49/`（`constbnd.dat` 45K / `bound_20.dat` 121K（原 .gz 已解压，不留重复副本）） |
| 取得日期 | 2026-09-29 |
| `constbnd.dat` | Delporte (1930) 边界的**折点表**：赤经（**小时**）、赤纬（度）、星座缩写、相邻星座。每个星座的第一行是"原点"（没有相邻星座），其后按**逆时针顺序**列出边界折点 —— 即拓扑是显式给的。共 1651 行 = 1651 条腿 |
| `bound_20.dat` | 同一套边界**已岁差到 J2000** 的点云（12,948 行，含 `O` 折点 1533 个与 `I` 插值点），但**按赤经排序** |
| 许可 | **公有领域**（ADC/CDS 机读目录；ReadMe 引用 Delporte 1930、Davenhall & Leggett 1989，无附加限制） |
| 为何不用 d3-celestial 的边界文件 | 同 §6.3 红线：来源不明的副本。这里用一手来源 |

### 怎么用（以及为什么）

1. **拓扑只能取自 `constbnd.dat`**。J2000 文件按赤经排序，且岁差把弧线从 1930 年的"等赤经/等赤纬"网格上挪开，所以
   按文件顺序连线会画成满屏竖条纹，按坐标分组只剩 20%，按"邻近重建"则会串到隔壁边界上（实测总长 6000–8800°，来回乱走）。
2. **折点要岁差到 J2000**（`Precession`，IAU 1976 / Meeus 21）。校验：把 `constbnd.dat` 的折点岁差过去，与
   `bound_20.dat` 的 J2000 折点比对，**中位偏差 0.0000°**。
3. **拓扑本身可自证**：Delporte 的边界每条腿都是等赤经或等赤纬的，实测 **1651/1651 条腿都在 0.02° 内轴向对齐**。

> 边界总长（各星座周长之和）实测 **9077°** —— 这是 IAU 划法的真实长度（不是"约 600°"，早先这个估计是错的）。

## 天文常数（本文件所载，供 S3+ 引用）

| 量 | 值（J2000 赤道坐标） |
|---|---|
| 银河北极 | RA 192.85948°，Dec +27.12825° |
| 银河中心 | RA 266.40499°，Dec −28.93617° |

`backgrounds/sky/sky.gd` 用这两个方向点亮 `shaders/dome.gdshader` 里的银河带，与恒星共用
`StarCat.direction()` 的同一套坐标约定，因此 `SkyRoot` 一转，银河与星空同步转。

> 注：`data/` **不放 `.gdignore`**。Godot 对 `.txt` 没有 importer（不会被导入，G12 的场景不适用），
> 而 `.gdignore` 会让该目录被导出器忽略——导出包会漏掉星表。见计划 §8 S8 待办。
