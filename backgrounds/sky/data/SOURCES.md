## `data/vsop87b.dat` — VSOP87B（木星、土星两行）

| 项 | 值 |
|---|---|
| 来源 | `https://cdsarc.cds.unistra.fr/ftp/VI/81/VSOP87B.jup`（484,519 字节）与 `.../VSOP87B.sat`（848,939 字节），Bretagnon & Francou，Bureau des Longitudes |
| 取得日期 | 2026-10-10（`curl --ssl-no-revoke`；本机 schannel 连不上吊销服务器，见 T17） |
| 取用范围 | **只取 VARIABLE 1/2/3（L/B/R）里 body=5（木星）与 body=6（土星）的行**；其余行星仍走 `planets.gd` 的 JPL 近似根数 |
| 截断 | 保留 **A ≥ 1e-6 rad** 的项：木星 325 项 / 土星 522 项（原表 3,625 / 6,365 项），文件 40 KB |
| 截断误差 | 对未截断级数在 1800–2050 每半年一点逐点比：木星 **0.43″**、土星 **0.24″** 的最大位置误差 |
| 许可 | **公有领域 / 公开天文数据**（IMCCE/CDS 机读目录；VSOP87 由 Bureau des Longitudes 发布，无附加条款） |
| 格式 | 每行 `<body> <variable> <power> <A> <B> <C>`，项 = `A·cos(B + C·T)`，T 为自 J2000 的儒略千年（365250 天）。坐标系 = 日心黄道、**J2000 春分点**——与 `planets.gd::ELEMENTS` 同一坐标系，所以换行不需要任何转换 |

### 为什么换这两行（而不换别的）

JPL 的近似根数是**直线速率**拟合：水星到海王星里只有木星、土星跟着**大不等式**（5:2 共振）摆，
直线拟合跟不上——对 Horizons 实测 1800–2050 差 425″ / 631″，超过「行星 < 5′」那条线。
两张表都实现过量过（README G33），都不行，所以这两行改由 VSOP87 级数回答。
其余五颗仍在 5′ 内（水星 21″、金星 42″、火星 60″、天王星 81″、海王星 59″，同一轮实测），保持不变。

## 二十八宿的**星官表**（`backgrounds/sky/mansion_figures.gd`，2026-10-10 全 28 宿）

三份来源、两次交叉。**进仓的只有一张"宿 → 星官 → 星名串"的表**（星名串 = 拜耳字母/弗氏号 + 星座，或 `HR nnnn`）：没有坐标、没有连线数据、没有第三方文件（§6.3 红线）。

| 来源 | 给出什么 | 怎么来的 |
|---|---|---|
| **中文维基百科**（`zh.wikipedia.org/w/api.php`，2026-10-10 取 wikitext，仅读） | ① 28 个宿条目的**星官表**：每宿的星官名 + **星数**（伊世同《中西对照恒星图表》1981 的星数）——共 **218 星官 1070 星**；② 各**星官条目**里的「中国星名 / 西方名称」对照表（同一份伊世同表） | 宿条目 → 星官清单与 213 个条目标题；`tables2()` 认表头（星官 + 星数），再从星官条目里取星名对照。表有好几种写法（无表头的两列表、带星图列的六列表、常福元编号的多列表、`* [[库楼一]]，ζ Cen` 的列表式），星名有繁简两体，`增` 星一律丢掉 |
| **SIMBAD**（`sim-id` / `sim-tap`，2026-10-10） | 把 Wikipedia 里的 **HIP 号、拉丁字母星（g Cen…）、弗氏号** 解成位置 | 位置 → 就近落回本仓 BSC5（**15″ 以内**才算落地：941 个 HIP 里 **911 个**在 15″ 内、30 个是 BSC5 没有的暗星；62 个字母/弗氏号里 46 个落地） |
| **Stellarium 中国星空** sky culture（`skycultures/chinese/index.json`，2026-10-10，643 KB，**不进仓**） | ① **连线形状**：星官分成几坨、每坨的走向（按 HIP 给）；② **27 个星官**的星（大角/招摇/骑阵将军/键闭/农丈人/九坎/司危/天钩/策/附路/天庾/积尸(胃)/积水(胃)/天阿/天谗/屎/御女/长沙/左辖/右辖/北落师门/天纲… 维基条目是"恒星条目"或压根没有星表） | HIP → SIMBAD 位置 → 本仓星表；**最终进仓的是星名串**，不是它的数据 |

### 三个人坑（都实际踩过，第二次不要再踩）

1. **SIMBAD 的 ASCII 输出赤经是"小时"**（要 ×15），而且取坐标的正则**必须贪婪**——非贪婪会把赤纬的角分吞掉，算出来的位置"看着合理"却差几十度（一个静默的错，不是报错）。
2. **`<ref name="x" />` 这种自闭合引用必须先剥掉**，再剥配对的 `<ref>…</ref>`：反过来时配对正则会把 `… />` 里那个 `>` 当成开标签的结尾，一路吞到很远处的 `</ref>`，**整张表跟着消失**（奎宿的 16 星表就是这么丢的；同理 `{{…}}` 与 `|` 混在单元格里也会把表切坏——`胃宿` 的本名星官就是这么丢的）。
3. **星名是繁体、宿表里的星官名是简体**：逐字对照要用一次 API 的 `variant=zh-cn` 转换（把页里出现过的 2099 个汉字整批转一次，得到的是**字级**映射，任何"星官名 + 一/二/三…"都能拼出来）；按整串转换会漏掉没进过转换表的那些星名。

| 数与差异 | 值 |
|---|---|
| 画出 | **209 星官 947 星 646 段**（星官条目里能读出 **890 行星名**，其中 **50 行**落不到 BSC5（比它的极限 V≈6.5 暗：羽林军 45→25、天垒城 13→9…；表侧现状 2026-10-15 探针实测：羽林军只剩 **20** 行、天垒城只剩 **8** 行，全表 **0 条解析不出来**）；**9 个星官**没星可画（神宫/鱼/积尸(鬼宿) 是 M7/M44 一类深空天体、十二国 连条目都没有、天稷/天庙/东瓯/军门/器府 是《仪象考成》就"今无"的）→ 缺星处**断链不搭桥**） |
| 两个来源的分歧 | 48 个星官上各差一两个星（多半是维基条目少列、或那几颗不在 BSC5）。有据可查的几处：`库楼九`（对照是 HD 107931，伊世同是 **D Cen = HD 106321**）、`天街二`（对照 50 ω² Tau，伊世同 **43 ω¹ Tau**）、`积水(井宿)`（对照 65 Aur，维基条目写 47 λ Per）、`外屏`、`阁道`、`军市`、`天园`、`天社`… —— **一律取伊世同表**，形状只借对照的分坨 |
| 不画的部分 | 清《仪象考成》给每个星官加的**增星**（角宿 41 星 → 95 星那 54 颗）不进表：它们是清代的补星，不是星官自己的星 |
| 标签落点（不是数据，记在这里因为它是"宿 = 一段"与"宿 = 一团"的差别） | 宿名原先立在**赤经跨度的正中**（分野的画法）；星官图上来之后实测这跟宿自己的星官**中位差 19.2°、最远 39.8°（尾宿）**。现在宿名取同名星官的锚点，赤道上只留 28 根距星刻（分划一根没少） |

## 天文常数（本文件所载，供天球各层引用）

| 量 | 值（J2000 赤道坐标） |
|---|---|
| 银河北极 | RA 192.85948°，Dec +27.12825° |
| 银河中心 | RA 266.40499°，Dec −28.93617° |

`backgrounds/sky/sky.gd` 用这两个方向点亮 `shaders/dome.gdshader` 里的银河带，与恒星共用
`StarCat.direction()` 的同一套坐标约定，因此 `SkyRoot` 一转，银河与星空同步转。

> 注：`data/` **不放 `.gdignore`**。Godot 对 `.txt` 没有 importer（不会被导入，G12 的场景不适用），
> 而 `.gdignore` 会让该目录被导出器忽略——导出包会漏掉星表。
